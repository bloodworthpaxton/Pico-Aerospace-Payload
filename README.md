The objective of this mission is to develop a conformal atmospheric probe designed to map macro-scale wind turbulence layers during high-velocity descent profiles. By integrating an MPU-6050 Inertial Measurement Unit (IMU) with a BMP280 barometric altimeter, the flight computer will dynamically cross-reference multi-axis rotational angular velocity against localized pressure altitudes. The resulting data matrix will be processed in Python to generate a 3D structural profile of boundary-layer atmospheric turbulence, providing critical environmental telemetry for aerospace vehicle launch trajectory planning.
